# ScaleFlow AI

Premium B2B automation and digital systems agency website built with React + Vite.

## Included
- Responsive premium marketing site
- Services and case studies
- Process and insights sections
- Interactive project inquiry modal
- Client-facing dashboard visual
- CMS-ready content architecture
- SEO-ready HTML metadata
- Vercel deployment configuration

## Run
npm install
npm run dev

## Build
npm run build
